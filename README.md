# Shawn Wong — Cybersecurity Portfolio

A static, responsive portfolio designed for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or serve the folder with any local web server.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The site will be available at `https://<username>.github.io/<repository>/`.
